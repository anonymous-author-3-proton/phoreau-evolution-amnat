# Contrasting and limited evolutionary responses of hydraulic-related traits to climate change in temperate forests: Data Analysis

This project contains the data, the code used to analyse it and to generate the figures present in the article "Contrasting and limited evolutionary responses of hydraulic-related traits to climate change in temperate forests" (Devresse et al. 202(6/7)) (Working title).

## Usage

- Install Positron from the official page https://positron.posit.co/download.html 
- Always run the 'Initialisation' section from the `make.R` script first
- Run the desired analysis scripts from the `make.R` to reproduce figures or tables, calling the `analysis` R scripts
- Run the `capsis_input_writing` scripts from the `make.R` if you want to remake the Phoreau input files (optional)
- Running Phoreau simulations:
    - Install java 1.8 on your system https://www.oracle.com/java/technologies/javase/javase8-archive-downloads.html 
    - From the directory ./capsis4_21636/ you can start capsis and Phoreau in interactive mode:
        - Running `capsis -l en` on Windows or `sh capsis.sh -l en` on linux (optional)
        - Then chose Forceps, then the setup file /phoreau-evolution-positron-project/capsis4_21636/data/forceps/phoreau-evolution/PhorEauAdaptive2Test.setup
        - You can modify the simulations parameters from this setup file
    - If you encounter an issue please refer to the capsis4 official documentation: https://capsis.cirad.fr/capsis/documentation 
- Run Phoreau simulations from the `make.R` calling `capsis_executing_scripts` R scripts if you want to rerun specific simulations (start small, heavy on ressources) /!\ change the `personal_OS` variable according to your system beforehand /!\
- If you cannot run capsis you can try to re-install capsis and Phoreau with the capsis-setup-21636-phoreau-evolution.jar installer:
    - Save the current ./capsis4_21636/ folder somewhere else in your computer and delete it here
    - Run the capsis-setup-21636-phoreau-evolution.jar installer and install capsis here under the name capsis4_21636
    - Delete the ./capsis4_21636/data/ directory and replace it with the former ./capsis4_21636/data/ directory from the previous capsis4_21636 installation you saved earlier
    - If it does not fix your problem verify your java version (see above), refer to the capsis documentation https://capsis.cirad.fr/capsis/documentation or contact authors
